# Cifra – Prototipos (Polaris Web Components 2.0-rc)

Prototipos HTML de Cifra Analytics. Abrir `index.html` (inventario de componentes) o cualquier pantalla en `modules/<dominio>/`.

Local: `node serve.js` → http://localhost:4321

- Tokens y base: `shared/globals.css`
- Componentes custom: `shared/components/<Name>/` (`.css` + snippet `.html`)
- Pantallas: `modules/<dominio>/` con su `<dominio>.css`
- Reglas para agentes y devs: `AGENTS.md` y `.agents/`
